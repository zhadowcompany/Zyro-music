# Zyro-music
Zyro-music: pemutar musik offline minimalis dalam satu file HTML. Impor lagu dari perangkatmu, buat playlist dan antrean, edit info lagu, equalizer 5 band, sleep timer, visualizer, lirik berjalan otomatis, statistik, dan backup data. Tema hitam putih dengan panel kaca dan wallpaper kustom. Tanpa akun, tanpa server, tanpa pelacakan.
